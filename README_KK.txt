MINISHOP — ТОЛЫҚ ДҮКЕН ЖОБАСЫ
=============================

МАҢЫЗДЫ:
- Бұл жоба жай HTML сайт емес: Node.js backend және SQLite дерекқоры қажет.
- GitHub Pages backend іске қоспайды. Сондықтан бұл жобаны Render, Railway немесе VPS сияқты Node.js хостингке орналастыру керек.
- Нақты ақша қабылдау үшін Freedom Pay мерчант аккаунты, Merchant ID және Secret Key қажет.
- Kaspi QR нақты қолжетімді болуы Freedom Pay-пен жасалған келісімге және мерчант аккаунтында қосылған төлем әдістеріне байланысты. Freedom Pay менеджерінен Kaspi QR-ды қосуды бөлек растаңыз.
- Код картаның нөмірін/CVV сақтамайды. Клиент Freedom Pay-дің қорғалған төлем бетіне өтеді.

1) КОМПЬЮТЕРГЕ ОРНАТУ
--------------------
Node.js 20 немесе одан жоғары нұсқасын орнатыңыз.
Осы папканы ашып, терминалда:

npm install

2) .env ФАЙЛЫН ДАЙЫНДАУ
-----------------------
.env.example файлын көшіріп, көшірмесін .env деп атаңыз.
Мына мәндерді енгізіңіз:

PORT=3000
BASE_URL=https://сіздің-backend-доменіңіз
SESSION_SECRET=ұзын-кездейсоқ-құпия-жол
FREEDOMPAY_MERCHANT_ID=FreedomPay берген ID
FREEDOMPAY_SECRET_KEY=FreedomPay берген құпия кілт
FREEDOMPAY_TEST_MODE=1

ТЕСТІЛЕУ ҮШІН 1 ҚАЛДЫРЫҢЫЗ.
Нақты төлемге тек Freedom Pay аккаунты өндірістік режимге ауыстырылғаннан кейін және барлық тексеруден соң 0 қойылады.

3) ІСКЕ ҚОСУ
-------------
npm start
Браузерде http://localhost:3000 ашыңыз.

4) ЖАРИЯЛАУ
-----------
GitHub Pages тек public/index.html файлдарын көрсете алады, server.js жұмыс істемейді.
Бүкіл жобаны Node.js қолдайтын Render/Railway/VPS хостингіне орналастырыңыз.
Хостингте:
- Build command: npm install
- Start command: npm start
- Environment variables: .env ішіндегі мәндерді хостингтің Environment бөліміне енгізіңіз.
- Persistent disk қажет: minishop.sqlite және sessions.sqlite файлдары жоғалмауы үшін.
- HTTPS домен қолданыңыз.
- BASE_URL мәні backend-тің HTTPS домені болуы керек.

5) FREEDOM PAY ҚОСУ
-------------------
Freedom Pay-ге бизнес/мерчант ретінде тіркеліп, тексеруден өтіңіз.
Merchant ID және төлемге арналған Secret Key алыңыз.
Freedom Pay жеке кабинетінде немесе менеджер арқылы мыналарды баптаңыз:
- Result URL: https://СІЗДІҢ-ДОМЕНІҢІЗ/api/payments/freedompay/result
- Сәтті төлем және қате төлем үшін қайту URL-дері.
- Қажетті төлем әдістері: Visa/Mastercard және Kaspi QR (егер сіздің келісіміңізде қолжетімді болса).
Алдымен тест режимінде сынаңыз. Нақты режимге тек провайдер рұқсат бергеннен кейін ауысыңыз.

6) ФУНКЦИЯЛАР
--------------
- Тіркелу және кіру (құпиясөз bcrypt арқылы хэштеледі).
- Тауар каталогы, іздеу, санат сүзгісі.
- Себет, тауар санын өзгерту, соманы есептеу.
- Сервер жағында тауар бағасын қайта есептеу.
- Тапсырысты SQLite дерекқорына сақтау.
- Freedom Pay hosted checkout-қа бағыттау.
- Серверден келетін төлем callback қолтаңбасын тексеру.
- Тапсырыстар тарихы.

ҚАУІПСІЗДІК:
- .env файлын ешқашан GitHub-қа жүктемеңіз.
- API кілттерін чатқа немесе браузер JavaScript-іне салмаңыз.
- Тек HTTPS пайдаланыңыз.
- Бұл бастапқы іске асыруды өндірістік ортаға шығармай тұрып, Freedom Pay-мен callback signature/merchant параметрлерін тестілеңіз.
